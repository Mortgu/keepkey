What was wrong

  1. Missing fonts in Docker. The Dockerfile installs LibreOffice with --no-install-recommends; on Debian all fonts are only "recommends". In the container Arial was rendered as DejaVu Sans – different line and page breaks than in Word / on a Mac, and bullets turned into boxes. Reproduced with your offer.docx.
  2. No timeout on LibreOffice. A hanging conversion blocked a worker slot forever (BullMQ keeps renewing the lock). Killing /usr/bin/soffice also leaves the real soffice.bin running.
  3. Broken templates were accepted. A template with a broken tag could be uploaded or saved from the DOCX editor and only failed at generation as "Multi error" – retried 3×.

What changed

  • Dockerfile: Liberation (metric-compatible Arial), Carlito, Caladea, DejaVu, OpenSymbol; libreoffice-writer-nogui; removed unused default-jre and ghostscript (a few hundred MB smaller); procps for pkill.
  • lib/docx-to-pdf.ts: timeout DOCX_TO_PDF_TIMEOUT_MS (default 90 s) that also kills the orphaned soffice.bin; max DOCX_TO_PDF_CONCURRENCY (default 1) LibreOffice per process; output must be a real PDF.
  • lib/docx.ts: templates are compiled on upload and on save from the editor → INVALID_TEMPLATE with the real reason (e.g. The tag beginning with "{orderId" is unclosed). Template errors during generation are UnrecoverableError – no pointless retries.
  • New translations INVALID_TEMPLATE (de/en), new tests lib/docx.test.ts.

DOCX vs ODT

Keep DOCX. docxtemplater is DOCX-only and the PDF comes from LibreOffice either way, so ODT would not fix anything – and the in-app DOCX editor needs DOCX.

Suggested next steps

  • Move LibreOffice out of the app image into a Gotenberg sidecar (HTTP API with its own timeouts, restarts and fonts).
  • Run API and worker as separate containers in production – start:api / start:worker already exist.
  • Check template tags against the schema on upload (today only a log warning → empty fields go unnoticed).
  • Repo cleanup: .~lock.order.docx#, backup .docx files, invoice copy.docx, committed shared/dist.
