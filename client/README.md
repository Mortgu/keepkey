# KeepKey Client

React-Frontend (Vite, TanStack Router/Query, Tailwind CSS v4).

```bash
pnpm install
pnpm dev        # Dev-Server
pnpm build      # tsc + Vite-Build
pnpm lint       # ESLint
pnpm test       # Vitest
```

Konventionen: siehe `AGENTS.md` im Repo-Root (Design-Token, Loading/Error-States, Toasts & i18n, QueryClient).
